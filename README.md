### Introduction
Welcome to the TikTokDB repository, a collection of information gathered on individuals who use TikTok. The aim of the project is to showcase how much information TikTok offers and what it can be used for.  

***Purposes of use***
- OSINT investigations
- Analytics, statistics & metrics tracking
- Agency progress

While the database contains information on random individuals, the platform does offer a blacklist and report system. Blacklisting allows users to pay a small fee to have their information completely removed. The report system is for information that users feel shouldn't be publicly accessible on our platform. If the report has a good enough reason, the information and listing will be completely removed.  

---

### How It Works
TikTokDB is actually split into three separate processes:  

***UtilityTok Database***
The actual platform - database listings along with an explore page, information and documentation.  

***UtilityTok Engine***
The process that sorts all information into categories, labels them and creates several formats and data structures.  

***UtilityTok AI***
The actual collection of information (in raw structures). The AI makes calls to the private mobile API as well as uses several third party services as backups (OmarThing, TikNinja, TikMatrix, APIfy, etc). If one method fails then there are others that the AI uses as a fallback. 

> [!NOTE]
> If not all of the information that can be collected is gathered, minimal information will always be displayed. We have hundreds of headless sessions running all at once which access authenticated web endpoints.
